# Рейтинг горнолыжных курортов России для каталога Travel Designer

Составной рейтинг 32 горнолыжных курортов в 20 регионах России. Он помогает решить, какие курорты первыми добавить в каталог туристического сервиса.

Прямой сопоставимой статистики посещаемости по каждому курорту в открытом доступе нет. Поэтому рейтинг собирается из косвенных признаков: регионального турпотока, инфраструктуры вокруг курорта, зимнего климата, доступности и цены ски-пасса. Главное в проекте — воспроизводимый расчёт: по каждому месту видно, из каких данных оно получилось, какие допущения использованы и насколько надёжны исходные данные.

> Рейтинг не является официальной статистикой посещаемости и не оценивает качество отдыха. Он показывает **потенциал** курорта по открытым данным.

**Главные выводы:**

- Топ-4 устойчив: он не меняется ни при разумной смене весов, ни при неизвестной цене. Состав топ-10 одинаков во всех четырёх сценариях данных.
- 28 из 31 пары соседних мест статистически не различимы. Поэтому решение для каталога принимается по группам, а не по точному месту.
- Сильнее всего на порядок влияют поездки в регион, снежные дни и рост поездок (проверка leave-one-out). Поездки и рост — показатели всего региона, а не конкретного курорта.
- Цены нет у 14 работающих курортов. Сильнее всего её сбор уточнит места Домбая, Игоры, Бобрового лога и Морозной горы.

## Методика

13 показателей переводятся в баллы 0–100 и складываются с весами в 5 компонентов:

| Компонент | Показатели (вес) | Источник |
|---|---|---|
| Региональный спрос, 40 | поездки 2025 (25), рост поездок 2025/2024 (10), ночей на поездку (5) | ЕМИСС 62157, 62489 |
| Инфраструктура, 25 | сегменты трасс (10), подъёмники (7), размещение (5), питание и места интереса (3) — в радиусе 6 км | OpenStreetMap, Overpass API |
| Зимние условия, 20 | снежные дни (8), морозные дни (6), снегопад за сезон (6) — средние за сезоны 2021/22–2025/26 | Open-Meteo, ERA5 |
| Доступность, 10 | расстояние до аэропорта по прямой (8), объекты транспорта (2) | OurAirports, OpenStreetMap |
| Цена, 5 | средняя цена взрослого дневного ски-пасса | сайты курортов, ручной сбор |

- **Нормировка.** Min-max, для поездок, объектов OSM, снегопада, расстояния и цены — по логарифму. Для расстояния и цены шкала обратная: меньше — лучше.
- **Рост и длительность.** Рост: −25% → 0, +25% → 100. Длительность: 1 ночь → 0, 7 ночей → 100.
- **Индекс** = Σ(балл × вес) / 100. **Место** = 1 + число курортов с большим индексом.
- **Уверенность** = 50 × полнота данных + 25 × есть цена + 25 × точные координаты. На место не влияет.
- **Пропуск цены** → балл 50 и флаг `missing price`.

Веса — рабочая гипотеза заказчика, они лежат в [`config/weights.yaml`](config/weights.yaml). Устойчивость к ним проверена на шаге 6: 5000 симуляций весов, +20% к каждому компоненту, исключение по одному показателю.

## Как запустить

Нужен Python **3.11+**.

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

make all                            # рейтинг → устойчивость → таблицы дашборда → тесты
```

Без `make`:

```bash
PYTHONPATH=src python -m resort_ranking.pipeline          # рейтинг и сценарии → data/mart/
PYTHONPATH=src python -m resort_ranking.stability         # интервалы и группы → data/mart/
PYTHONPATH=src python -m resort_ranking.dashboard_export  # таблицы дашборда → data/dashboard/
python -m pytest -q
```

Повторный запуск на тех же файлах из `data/raw/` даёт тот же результат: у симуляций зафиксирован seed. Сеть для расчёта не нужна. Сбор данных из API заново запускается отдельно — `python src/collect_with_overrides.py`, сначала можно с `--dry-run`.

## Допущения и отличия от исходной методики

- **Ряды Росстата.** Поездки в исходном расчёте взяты из месячного (оперативного) ряда, ночёвки — из квартального. Базовый расчёт сохраняет это, чтобы воспроизвести контроль. Сверка всех рядов — `data/reference/region_manual_check.csv`.
- **Погода.** Модель ERA5, а не ERA5-Land. В исходных данных три курорта Красной Поляны получили погоду из одной ячейки сетки, поэтому снегопад у них одинаковый. Погода нового сбора вынесена в отдельный сценарий, а не подставлена молча.
- **Координаты.** Проверены вручную 15.10.2026: 11 подтверждены, 20 уточнены, 1 не найдена.
- **Цены.** Ручной сбор 27.10–01.11.2026, тарифы сезона 2025/26. Курорты, где нет дневного билета (оплата за подъём, почасовые абонементы), получают балл 50 по правилу ТЗ, с пояснением в данных.
- **Дата выгрузки Росстата.** В файлах её нет, в `config/sources.yaml` указана дата получения архива (14.10.2026).

## Ограничения

1. Региональный турпоток не показывает посещаемость отдельного курорта.
2. Полнота OpenStreetMap различается между регионами.
3. Радиус 6 км не совпадает с границами комплексов. У 8 пар курортов радиусы пересекаются — флаг `OSM radial overlap`.
4. ERA5 сглаживает перепады высоты и не заменяет метеостанцию на склоне.
5. Расстояние до аэропорта по прямой — не время в дороге.
6. Цена известна не для всех курортов и меняется по дням.
7. Min-max нормировка зависит от состава выборки.
8. Веса — гипотеза, а не доказанная причинная связь.
9. Оперативные данные Росстата могут пересматриваться.
