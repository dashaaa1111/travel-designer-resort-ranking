# Шаг 7: экспорт данных для дашборда

Четыре плоские таблицы для DataLens (или другого BI). Всё, что показывает дашборд, берётся из них, без формул в BI.

Новые и изменённые файлы:

- `src/resort_ranking/dashboard_export.py` — сборка таблиц
- `config/sources.yaml` — источники, у которых дата не записана в файле данных (Росстат, цены, ручная проверка координат)
- `tests/test_dashboard_export.py` — тесты
- `src/resort_ranking/pipeline.py` — загрузка цен вынесена в `load_price_rows`, расчёт не изменился
- `src/resort_ranking/overlays.py` — у ручных цен сохраняются ссылка и дата проверки
- `Makefile` — цель `dashboard`, `make all` = run + stability + dashboard + test

Запуск: `make dashboard` или `make all`. Результат: `data/dashboard/`.

| Файл | Строка | Что внутри |
|---|---|---|
| `dashboard_resorts.csv` | курорт (32) | место, интервал «5–7», P(топ-5/10/15), группа, вклад и балл 5 компонентов, главный плюс и минус относительно среднего, флаги качества (по колонке на флаг), границы по цене, ключевые сырые значения, ссылки, дата обновления |
| `dashboard_metrics_long.csv` | курорт × показатель (416) | сырое значение и единица, балл, средний балл по 32, вес, вклад в индекс, `imputed`, `source_id`, ссылка, дата сбора, период данных, пояснение |
| `dashboard_scenarios_long.csv` | курорт × сценарий | место, балл, уверенность, сдвиг к baseline, признак основного сценария |
| `sources.csv` | источник | название, URL, файл, период, дата сбора, откуда взята дата, какие показатели даёт |

Соединения в BI: все таблицы с `dashboard_resorts` по `resort_id`, `dashboard_metrics_long` с `sources` по `source_id`. У цены, собранной из двух файлов, `source_id` содержит оба через `;`.

## Правила

- **Компоненты.** Вклад компонента = Σ(балл × вес) / 100. Сумма пяти вкладов равна индексу с точностью до округления. Балл компонента = средний балл показателей с учётом весов (0–100).
- **Главный плюс и минус** (`main_driver`, `main_drag`) — компоненты, вклад которых сильнее всего выше и ниже среднего по 32 курортам.
- **Даты.** Источники API берут дату из файла сбора. Цены и координаты — из строк файла (последняя дата проверки). Росстат — из `config/sources.yaml`: в выгрузке даты нет, стоит дата получения архива (14.10.2026). Если узнаете точную дату выгрузки ЕМИСС, исправьте её там.
- **Цена без данных.** `imputed = True`, балл 50 по правилу ТЗ. В `note` указано, проверяли ли цену и почему она не вошла в расчёт (например, на курорте нет дневного билета, только оплата за подъём).
