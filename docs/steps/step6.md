# Шаг 6: интервалы мест и группы курортов

Проверка устойчивости рейтинга: насколько порядок курортов зависит от весов (рабочая гипотеза заказчика) и от недостающих цен. Базовый `popularity_score` и `rank` не меняются, результаты пишутся в отдельные файлы.

Новые и изменённые файлы:

- `src/resort_ranking/stability.py` — Монте-Карло по весам и цене, +20% по компонентам, leave-one-out, границы по цене, правило групп
- `config/stability.yaml` — параметры симуляции и правило групп (меняются только здесь)
- `tests/test_stability.py` — тесты формул, воспроизводимости и проверки на реальных данных
- `notebooks/06_intervals_groups.ipynb` — анализ, графики и выводы
- `Makefile` — цель `stability`, `make all` = run + stability + test

Запуск: `make stability` или `make all`.

Результаты в `data/mart/`:

| Файл | Что внутри |
|---|---|
| `rank_intervals.csv` | по курорту: базовое место, интервал p05–p95, медиана, P(топ-5/10/15), группа, различим ли порядок с соседом |
| `component_sensitivity.csv` | место и сдвиг каждого курорта при +20% к каждому из 5 компонентов |
| `component_sensitivity_summary.csv` | по компоненту: Спирмен, средний и максимальный сдвиг, кто вошёл в топ-10 и выпал из него |
| `leave_one_out.csv` | по каждому из 13 показателей: как меняется порядок без него |
| `price_bounds.csv` | курорты без цены: место при самой высокой и самой низкой цене |
| `stability_summary.json` | параметры запуска и состав групп |

## Методика

- **Веса:** Dirichlet со средним, равным весам ТЗ, `concentration=200`. Сумма в каждой симуляции равна 100.
- **Цена:** у курортов без цены ценовой балл равномерно распределён от 0 до 100 вместо фиксированных 50.
- **Симуляции:** 5000, seed 42, поэтому повторный запуск даёт тот же результат. Место считается по правилу ТЗ: `1 + число курортов с большим баллом`.
- **Интервал:** 5-й и 95-й процентили методом ближайшего ранга.
- **Группы:** правило проверяется сверху вниз. A — P(топ-5) ≥ 0.8, B — P(топ-10) ≥ 0.8, C — P(топ-15) ≥ 0.5, D — остальные, X — курорт не работает.

## Результат (сценарий verified)

- A: Газпром Поляна, Красная Поляна, Роза Хутор, Сорочаны.
- B: Архыз, Домбай, Шерегеш, Игора, Горный воздух.
- C: Бобровый лог, Губаха, Чегет, Морозная гора, Эльбрус, Большой Вудъявр.
- X: Аджигардак, КолаСпортЛэнд.
- Сильнее всего на порядок влияют поездки в регион, снежные дни и рост поездок (leave-one-out).
- При concentration 100 и 500 и другом seed ни один курорт не меняет группу.

## Ограничения

Интервалы отражают неопределённость весов и цены, но не ошибки в самих признаках (OSM, ERA5, Росстат). Нормировка min-max по 32 курортам в симуляции не меняется.
